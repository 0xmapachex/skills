# Brand intake checklist

Gather these before generating. Recommend the user drop a **brand folder**; pull what you can from it, then ask only for the gaps. Save the result as `brand-profile.md` so future runs skip intake.

## Recommended brand-folder contents
- **Logo** — SVG preferred (recolorable), plus PNG fallback. Note symbol-only vs symbol+wordmark.
- **Colors** — exact hex values: primary, accent (the highlight color), text, background.
- **Fonts** — brand typeface name; a close web font for compositing (e.g. Inter as a Geist substitute).
- **Brand / voice guidelines** — tone, do/don't words, capitalization rules.
- **Website URL** — for positioning, offer, proof, tone.
- **Audience** — who actually buys; how they talk.
- **Offer / pricing** — trial, price, guarantee, the primary CTA.
- **Example posts** — what they've shipped (style reference).
- **Reference ads** — 2-3 they like + 2-3 they dislike (taste calibration).

## brand-profile.md — fields to fill
```
Brand: <name>
Logo: <path to svg/png> (symbol-only? wordmark?)
Colors: accent <#hex>, text <#hex>, bg <#hex>
Font: <brand font> / compositing font <web font>
Voice: <2-3 lines: register, do/don't, banned words>
Audience: <who buys; how they speak; language/locale>
Product (one line): <what it does for them>
Offer: <trial / price / guarantee>
Primary CTA: <e.g. native "Send message" for click-to-WhatsApp; or "Learn more">
Formats: <IG Story 1080x1920 / IG Feed 1080x1350 / ...>
Taste notes: <from reference ads — what to emulate / avoid>
```

## If no folder is provided
Ask, in priority order: brand name + logo → accent color → audience + voice → the offer → target format. That's enough to make the first ad; backfill the rest later.
